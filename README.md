# mos-scan

Kamera-scanner vir die MOS Rak-telling-app (Mariental One Stop).

Google Apps Script laat nie die kamera binne sy raam toe nie. Daarom maak die telblad hierdie bladsy oop met die 📷-knoppie. Dit lees die barcode en stuur die kode terug na die app.

- Bevat geen data, name of PIN's nie.
- Barcode-leser: [html5-qrcode](https://github.com/mebjas/html5-qrcode) 2.3.8 (Apache-2.0).
